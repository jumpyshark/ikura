# 連続撮影と確認画面（最新版）

この文書は manual-capture-review.md の撮影手順を更新する。

- 「写真を撮る」からアプリ内カメラを直接開く。シャッターを押すたびに写真が追加され、同じ画面で最大10枚撮影できる。サムネイルから削除できる。
- 「完了」で各写真を順番に切り取り候補・白黒コントラスト補正・文字読み取りに通す。事前の画像確認ボタンは不要。
- 最後に画像と編集可能な支出情報を同じ画面で確認し、「確認して保存」で初めてDBに保存する。重複確認も維持する。
- 読み取れない画像も手入力・画像調整・スキップを選べる。
- 「画像を調整・撮り直す」は現在の画像を開く。切り取り範囲は画面内に収まる専用エディターで調整する。スクロールとの競合を避け、画像とハンドルの座標を一致させる。
- モーダル内に独立したSafeAreaProviderを置き、ステータスバーやホームインジケーターとの重なりを防ぐ。
- カメラは非表示・バックグラウンド時に解除する。自動シャッターは使わない。
- 決済スクリーンショットは従来どおり全体・元の色から始める。紙レシートの補正も元に戻せる。

## ビルドと確認

Expo SDK 56対応のexpo-camera 56.0.8を追加。既存のExpo/RN/OCRパッチのバージョンは維持する。新しいIPA/APKが必要。

TypeScript、25件のテスト、iOS/Android JavaScriptバンドル、iOS prebuild（依存インストールなし）を確認済み。ネイティブコンパイルと実機でのレイアウト・カメラ検証は未実施。

実機では、3枚の連続撮影、撮影中の戻る・バックグラウンド移行、長いレシートの四隅操作、補正の取り消し、読み取り失敗時の手入力とスキップ、保存後の再起動を確認する。自動切り取りは長方形の候補であり、射影補正や境界検出精度を保証するものではない。
